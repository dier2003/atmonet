# Contributing to AtmoNet

Thank you for your interest in improving AtmoNet.

## Development workflow

1. Fork or clone the repository.
2. Create a feature branch.
3. Make focused changes and test them locally.
4. Keep secrets and `.env` files out of Git.
5. Open a pull request with a clear description of the change.

## Code guidelines

- Keep frontend components readable and reusable.
- Keep API and ML-service responsibilities separated.
- Document new environment variables and API endpoints.
- Do not commit credentials, private keys, or generated dependency folders.

## Reporting issues

When reporting a bug, include the affected component, steps to reproduce, expected behavior, actual behavior, and relevant error messages.
