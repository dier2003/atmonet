# FloodGuard

Professional Flood Detection & Early Warning demo system.

## Run
Open two terminals.

### Backend
cd backend
npm install
npm run dev

### Frontend
cd frontend
npm install
npm run dev

Frontend: http://localhost:5173
Backend: http://localhost:5000

This demo uses local sample data and a transparent risk engine so it runs immediately.
Replace the risk engine with your trained ML model/API when ready.
